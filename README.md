# Royal Indian Traditional Digital Invitation

An interactive, ultra-cinematic web-based digital invitation for the grand inauguration of **Swaroop Narayan Service Provider (स्वरूप नारायण सर्विस प्रोवाइडर)**. 

Designed with a rich, luxury traditional theme featuring deep maroon, royal red, and antique gold tones, shehnai/celebration background music, animated doors, flickering diya, and canvas-based floating marigold and rose petals.

## 🎬 Features

* **3D SVG Temple Doors**: Ornate golden temple gates that split and slide open with perspective transitions.
* **Canvas Particles**: High-performance rendering of falling rose petals, marigold petals, and floating gold sparkles.
* **Upbeat Celebration Audio**: Plays celebratory instrumental music upon opening, with a seamless traditional shehnai fallback.
* **Timeline Controls**: Play/pause timer, progress bar tracker, manual page dots, and volume mute controls.
* **Touch Swipe Navigation**: Mobile gesture support allowing users to swipe left/right to navigate between pages.
* **Fully Responsive**: Adapts fluidly to all screen dimensions (desktop, tablet, portrait mobile, and landscape mobile).

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in your web browser, or host it locally:

```bash
# Using Python
python -m http.server 8080

# Using Node.js (any static server tool)
npx serve .
```

Open `http://localhost:8080` to experience the invitation.
